# LearnBridge

LearnBridge is a responsive bilingual educational-resource platform being
developed with HTML, custom CSS, and vanilla JavaScript.

The platform will support English and Arabic, including correct LTR and RTL
layouts.

## Project status

The project is currently in Phase 1: development environment and Git setup.

## Planned features

- Responsive multi-page interface
- English and Arabic localization
- LTR and RTL layouts
- Educational-resource search
- Resource filtering and sorting
- Saved bookmarks
- Dark mode
- Contact-form validation
- WhatsApp contact links
- Accessibility improvements
- GitHub Pages deployment

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git
- GitHub
- GitHub Pages
